Gérer les articles

Pages CMS enregistrera les articles et leurs photos dans le dépôt GitHub. GitHub Pages les affichera après la publication de la branche configurée.

Avant la première connexion, publie cette configuration et le catalogue sur GitHub.

  1. Connecte-toi à Pages CMS avec le compte GitHub qui possède le dépôt.
  2. Autorise Pages CMS à accéder au dépôt camille74250/Ma-poulette.
  3. Choisis la branche publiée par GitHub Pages (la branche courante du dépôt est main), puis ouvre Articles de la boutique.
  4. Ajoute ou modifie les articles et enregistre : les changements seront publiés par GitHub Pages.
Ouvrir Pages CMS

La première connexion nécessite d’autoriser l’application GitHub Pages CMS. Ne partage jamais tes identifiants GitHub ou tes clés d’accès.
