Gérer les articles

Le catalogue reste dans GitHub. Cloudflare Pages publiera automatiquement le site après chaque mise à jour de la branche main.

  1. Dans Cloudflare, ouvre Workers & Pages, puis crée une application Pages reliée à GitHub.
  2. Autorise le dépôt camille74250/Ma-poulette et sélectionne la branche main.
  3. Choisis le preset None, la commande de build exit 0 et le dossier de sortie . (racine du dépôt).
  4. Déploie le site. Son adresse gratuite se terminera par .pages.dev.
  5. Pour gérer les produits, connecte-toi à Pages CMS et ouvre Articles de la boutique. Chaque sauvegarde dans GitHub déclenchera un nouveau déploiement.
